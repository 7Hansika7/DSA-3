Dictionary-Based Spell Checker (Trie + Edit Distance)

Tokenizes input text and queries each token in the Trie (O(L)). When a word is missing from the lexicon, the SuggestionEngine calculates Damerau-Levenshtein Edit Distance via Dynamic Programming with Soundex phonetic tie-breaking, ranking the Top 3 Suggestions for instant replacement.

KMP (Knuth-Morris-Pratt) — Automatic Error Detection & Index Locator

Automatically detects all misspelled words using Trie dictionary lookup, then runs KMP (Knuth-Morris-Pratt) on each detected error to find its precise [start...end] character indices, line/column coordinates, and surrounding context. Also shows the LPS (Longest Prefix-Suffix) Table built per error pattern and the Top 3 Suggestions per error. Time: O(n + m) — zero backtracking.

Aho-Corasick — Automatic Multi-Pattern Error Scanner

Automatically detects all misspelled words using Trie dictionary lookup, builds the Aho-Corasick Automaton from all detected error words, then scans the entire text in a single pass of O(n + z) time — matching ALL error patterns simultaneously using BFS Failure Links and Dictionary Output Links. Reports every match with its exact character indices.

Network Flow (Max Flow) Bipartite Suggestion Matcher

How Max Flow Gives Suggestions: In complex sentences with multiple spelling errors, greedy individual word correction can cause collisions where two errors compete for the same dictionary word. By modeling error repair as a Maximum Bipartite Matching Network (Source S ➜ Errors ➜ Candidate Suggestions ➜ Sink T), Max Flow finds the globally optimal, collision-free assignment.
